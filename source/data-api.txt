.. banner::
   :variant: warning

   The Atlas Data API and HTTPS Endpoints reached end-of-life on
   **September 30, 2025** and are no longer available. Requests sent to
   Data API endpoints will fail. This page is retained for reference
   only. To learn about the deprecation and migration alternatives, see
   :ref:`Data API and HTTPS Endpoints Deprecation <data-api-deprecation>`.

The Data API was a managed service that let you securely work with data
stored in Atlas using standard HTTPS requests. The Data API was not a
direct connection to your database. Instead, the API was a fully-managed
middleware service that sat between your cluster and the clients that
sent requests.

MongoDB deprecated the Data API and HTTPS Endpoints in September 2024.
The services reached end-of-life on **September 30, 2025** and are no
longer available.

If your application used the Data API or HTTPS Endpoints, migrate to an
alternative solution, such as MongoDB Drivers with a native language
framework, MongoDB Drivers with cloud-native functions, or a partner
solution. To learn about these alternatives and migration guidance, see
:ref:`Data API and HTTPS Endpoints Deprecation <data-api-deprecation>`.
